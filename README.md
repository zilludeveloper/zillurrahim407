# Zillur Rahim — Bio Site (v2)

Self-contained single-page site: `index.html` (CSS and JS inline), `avatar.jpg`, `favicon.svg`. No build step, no external fonts or scripts.

Preview: `python3 -m http.server 8080` in this folder, then open http://localhost:8080

## Contact details
Only email and LinkedIn are shown. The phone/WhatsApp number is NOT in any file.
To add WhatsApp: in `index.html`, find the `WHATSAPP (off by default)` comment in the Contact section and replace the comment with the `<a ...>` line inside it, with your number in place of `880XXXXXXXXXX`.
